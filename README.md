## Description

FunPrint is a modern, high-performance custom apparel and merchandising e-commerce platform built for both individual retail shoppers and high-volume corporate clients. Combining interactive 3D apparel visualization with direct-to-garment custom printing workflows, FunPrint delivers a seamless shopping and ordering experience across all devices. The platform features an end-to-end administration control center for managing verified payments, real-time catalog inventory, order lifecycles, authentic brand partnerships, and live telemetry analytics.

## Features

### 3D Interactive Apparel Viewer
- Real-time 3D rotation and zoom for t-shirts and hoodies
- Dynamic color switching with realistic fabric textures and lighting
- Instant print artwork and logo placement previews

### Custom Design & Print File Generation
- High-resolution logo and graphic file upload for front, back, and sleeve placements
- Automated print file compositing and mockups for factory production
- Drag-and-drop customization interface with precise positioning controls

### Retail & Bulk Ordering Workflows
- Multi-tier ordering support for single retail pieces as well as large-scale bulk factory orders
- Dynamic quantity-based wholesale pricing and quotation request pipelines
- Direct enquiry submission system for retail custom, factory bulk, and corporate apparel

### Brand Collaborations & Curated Lookbooks
- Dedicated brand partner showcase highlighting collaborations
- Interactive catalogue viewer and digital lookbook downloads
- Direct brand collaboration and partnership enquiry routing

### Streamlined Checkout & Payment Verification
- Multiple checkout payment options including Cash on Delivery and Direct UPI transfer
- Manual payment proof submission with instant receipt confirmations
- Dedicated admin verification queue for confirming and tracking payment transactions

### Admin Control Center
- Unified dashboard with real-time business performance indicators
- Complete order lifecycle management from placement to delivery
- Live product catalog management with stock tracking and inventory alerts
- Customer directory tracking active accounts and purchase history
- Enquiry management console for triaging incoming business leads
- Official Vercel Web Analytics integration tracking live visitors, page views, and geographic distribution
